# Portfolio Neemias (scaffold)

Este é um scaffold Vite + React + Tailwind com os componentes do seu portfólio.

Como usar (Windows PowerShell):

1. Instalar dependências

   npm install

2. Rodar o servidor de desenvolvimento

   npm run dev

Observações:
- O cliente de API `base44` é um mock que retorna projetos de exemplo.
- Ajustei pequenos typos JSX (por exemplo `href__` -> `href`, `ref__` -> `ref`) para que o app rode.

Se quiser que eu conecte a um backend real (Supabase, Base44, etc.), me diga as credenciais ou a URL do endpoint e eu faço a integração segura.
